# Implementation decisions and deviations

1. Use Python 3.11+ and libraries available in a CPU-only environment. All offline core experiments are 8×8 to 32×32 and no pretrained weights are used.
2. Use an explicit 2-block ViT with 2 heads, no dropout, learned positions and mean pooling. A training batch is 32; AdamW and validation-only early stopping. Neural budgets are **not** exactly matched across CNN and ViT; report parameter counts.
3. E02 uses the single-patch equivalent of general A to avoid forming a large Kronecker product. Unit tests independently verify global operator equivalence.
4. MC chance-risk at alpha=0 must use a deterministic constant classifier for an exactly null signal: numerical ~1e-16 residuals would otherwise induce misleading classification correlations. This bug was detected in initial unit tests and repaired before primary experiments.
5. Use independent split seeds and distinct base IDs for S1. Gaussian values are never clipped; pixels in bounded tasks are generated in [0,1].
6. Mean TAR initially compared randomly phased gratings (empirically mean-matched) to XOR and thus could not support a clear **mean-shift positive control**. After seeing this limitation in E04, a marker-position variant was **added as an exploratory, post-registered check** with `include_marker: true`; earlier E04 logs remain available. This variant is not misrepresented as preregistered.
7. Both E07 label families are controlled. A periodic checkerboard is annihilated by the linear 5×5 binomial filter, but the clipped noisy signal-family images have not been proved label-independent after filtering. The measured probe degrades; the nuisance family did not improve (already saturated). This qualification corrects the original stronger interpretation during the 2026-11-14 review.
8. E08 stride=2 has 72 output scalars versus stride=4's 32. We report the rank improvement but do not infer overlap superiority under matched compute.
9. E10 natural MNIST is an opt-in data download and remains NOT RUN. Code path is provided for explicit execution, but no natural-image results are claimed.
10. The requirement suggested F6 alignment *versus epoch*; recorded training histories include this. Figures are derived from actual run records. Plotting uses Matplotlib defaults without smoothing.
11. `requirements-lock.txt` freezes the directly imported packages in the execution environment, and `docs/environment_freeze.txt` separately records every installed package; this does not guarantee cross-platform exact binary reproducibility.
12. The repeated seed-0 experiment records (core then full) are intentionally retained, but **not counted as independent stochastic evidence**. Reported three-seed means use one run per seed.
13. The 2026-11-14 corrected cohort is isolated in `runs/review_20261114` and `reports/review_20261114`. Historical runs are preserved. Source/config cohorts must be selected explicitly; incompatible conditions are rejected rather than pooled.
14. S1 random bases are constrained perpendicular to the planted direction so raw zero-risk claims apply to the implemented distribution. Token-space whitening independently checks Gaussian risk. Monte Carlo labels are IID, with exact pointwise binomial intervals and no absolute signal cutoff. All corrections and their tests are listed in `scientific_review_20261114.md`.
15. Noiseless XOR is a finite-support sufficiency control. E05 matched uniform-phase offsets have the same population distribution and are not an out-of-distribution translation study. Neither limitation is repaired by relabeling the measured experiment as a stronger one.
