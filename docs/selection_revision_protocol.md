# Revision protocol, frozen before revision outcomes

Date: 15 November 2026. This is a locally specified revision protocol, not an external preregistration. Historical CIFAR results informed it. CIFAR revision results are corrected replications; SVHN is the independent external-domain evaluation. Preserve the original and exploratory cohorts unchanged.

Question: can inexpensive statistical scores select frozen linear patch operators usefully under controlled scalar-feature and dense-projection budgets? No new theorem, full-transformer transfer, universal winner, or journal-acceptance claim is intended.

Use `configs/selection_revision.yaml`: CIFAR-10, CIFAR-100, cropped SVHN; seeds 10--14; budgets 256/768; the same fourteen operators and ImageNet normalization; 1,000 operator-fit, 1,000 diagnostic and 500 validation training images. Head training uses 2,000 labeled images (operator-fit labels are revealed only for head training). Diagnostics use 1,000 labels; validation uses a further 500 labels. Train ridge heads on the declared thirteen-value penalty grid, 10^-2 through 10^10, with validation-only selection, ties to larger penalties. Report endpoint selections, never silently extend the grid after observing test results.

Protocol amendment before final-cohort execution: the first partial revision run used an upper penalty of 10^7. Reviewing the historical follow-up protocol revealed that two historical heads selected 10^8. That partial run was stopped, retained in `runs/selection_revision`, and excluded from all final tables. The final grid extends through 10^10 to encompass the known historical boundary. No partial-revision accuracy or regret tables were inspected to choose this amendment. The final cohort is `runs/selection_revision_final`; all its operators, scores, heads and outcomes are recomputed under the amended frozen protocol.

Before splitting, hash every raw image. Exclude from the official training pool every exact duplicate after its first occurrence, every content group with inconsistent training labels, and every image whose content occurs in the official test set. Stratify only the remaining training pool. Evaluate ALL official test images, with their natural class frequencies, including any repeated test content; disclose duplicate counts. No test labels enter fitting, scoring, penalty selection or deduplication. Save official IDs, hashes, excluded counts and class counts. Content deduplication addresses exact duplicates, not near duplicates. The fixed policy is p04_dct at both budgets, chosen using the already observed CIFAR development evidence and locked here before any SVHN outcomes. It is prospective only for SVHN; CIFAR evaluation is descriptive. Do not call re-used CIFAR domains independent policy validation.

Selectors: rank (uniform tie expectation), reconstruction, mean retention, covariance retention at lambda=.1, cross-fitted retention, fixed-shrinkage H-score, adaptive Ledoit--Wolf H-score including its (1-alpha) multiplier, profile-evidence LogME, a fixed-alpha diagnostic probe, a diagnostic probe maximizing held-out diagnostic accuracy over the declared grid, and fixed p04_dct. Profile LogME maximizes the published Gaussian evidence objective after profiling beta, with a broad log(alpha/beta) grid, bounded refinement of every grid-local maximum, and an analytic null-model boundary. Save optimizer success, search bounds and classwise parameters; fail on unsuccessful numerical refinement. This is an independent implementation with centered/scalar-normalized features and uncentered one-hot targets, not bitwise author-code reproduction. Historical eleven-step LogME is preliminary only.

Freeze all scores, eligible sets, selected penalties, sensitivity scores for lambda=.01/.5 and within-patch-size choices to disk before test inference. Save every operator, chosen head, full prediction vector, validation curve, source snapshot and pretest hash. Report per-domain/budget absolute accuracy, regret, Spearman correlation, fractional selection frequencies, paired differences and intervals. Regret uses a finite-bank empirical test oracle, so is a descriptive, potentially optimistic reference. Matching p and B matches dense projection dimensions, not whole-transformer compute.

Uncertainty: resample training-seed blocks within each observed domain, preserving budgets and selectors, plus common test-image bootstrap weights shared across every seed, budget and selector in that domain. Use a multinomial bootstrap over image joint-correctness patterns (exactly equivalent to resampling images for mean accuracy differences). Report seed-only and joint seed/image paired intervals, conditional on the three domains and fixed test sets; do not interpret three domains or five seeds as population-domain evidence. For an honest fixed-policy comparison report accuracy gains on SVHN separately. No claim of multiple-comparison-corrected superiority.

Cost: measure each selector in a fresh process on seed 10 of every dataset and both budgets, repeated three times, with identical two-thread limits and pre-fitted operator banks. Include ALL feature extraction and statistics required by that method, plus marginal scoring; record peak RSS and incremental sampled RSS (10 ms sampling). Bank fitting is a separately timed shared prerequisite and is added once to cold selection time, and is amortized if already fitted. Exclude downstream evaluation-head fitting, test inference, imports, input decoding and checkpoint loading from selection timing; include a separate shared selected-head fit time. Fixed policy evaluates no bank features. These are costs for the declared low-label setting, not a guaranteed application speedup.

Sensitivity analysis is secondary: shrinkage .01/.1/.5; matched-p subsets; per-family H-score/correlation summaries; validation-grid endpoint counts; original-versus-revision result changes (not attributed solely to deduplication, since seeds/test sets/baselines also change). Reproduce the exact historical duplicate-exclusion deltas separately from saved predictions. All table cells must trace to measured artifacts.
