# Mathematical derivations and boundaries

Let n=HWC, m=p²C, N=HW/p², and x=vec(image) in R^n. Raw patch flattening is the permutation matrix Q∈R^{n×n}, containing one 1 per row and column, so Q^TQ=I. `patchify` is an **isometry**; exact ordered `unpatchify` is its inverse. Larger p alone therefore does **not** eliminate pixels.

Let W∈R^{d×m} be fixed, and A=(I_N⊗W)Q. Multiplication by Q preserves rank; rank(I_N⊗W)=N rank(W). Consequently A is injective iff W has full column rank m. Its kernel has dimension N(m-rank(W)). Offsets from bias or *known, ordered* positional embeddings cancel in pair differences. A bag-of-tokens representation that discards position is a different (potentially non-injective) map and is **not** covered by this rank criterion.

If rank(W)<m, choose a unit null vector u, an interior base image b with each pixel in [0.34,0.66], and a patch-local perturbation δ = Q^T(e_j⊗u). For ε≤0.2/||u||∞, the images b+εδ and b−εδ are distinct and bounded in [0,1], but A(b+εδ)=A(b−εδ). With a balanced two-point label task, all classifiers that observe only Ax have posterior Pr(Y=1|Ax)=1/2 and risk 1/2. The full image deterministically distinguishes the labels (risk zero). This is an adversarial construction for a particular fixed W, not a typical-case statement or lower bound for trainable W.

For the balanced Gaussian location model X|Y=y∼N(μ+yv/2,σ²I_n), the log likelihood ratio under a linear representation z=Ax+b is `(Av)^T (σ² A A^T)^† (z - Aμ - b)`. Hence its sign is the optimal classifier. Under each label, the score has mean ±(v^T P_A v)/(2σ²) and variance `(v^T P_A v)/σ²`, with P_A=A^T(AA^T)^†A the row projector. Thus error is Phi(-sqrt(v^T P_A v)/(2σ)). The result extends to singular AA^T by pseudoinverse; if v∈ker(A), the two induced class distributions coincide and the error is 1/2. For A full column rank P_A=I, the risk equals the full-image Bayes risk.

Define α=||P_Av||/||v|| for nonzero v and TAR=α². For independent patches, use P_W on each patch; this is exactly P_A up to Q. In multiclass samples, class mean scatter B_j=sum_c π_c(μ_cj−μ_j)(μ_cj−μ_j)^T and TAR_mean = sum_j tr(P_W B_j)/sum_j tr(B_j) if denominator positive. It is a retained *mean energy* score and can be undefined when every conditional mean agrees. XOR labels can have identical conditional means and still be determined exactly by the full data or a sufficiently rich nonlinear feature decoder.

Data-processing inequality I(Y;Z)≤I(Y;X) is valid for Y→X→Z; equality is possible when Z is sufficient for Y. It is not a statement that any reduction in dimension must worsen Bayes risk on every task. Theorems assume deterministic linear token maps and ideal access to the complete ordered token sequence; none proves generic ViT test accuracy, natural-image prevalence, or quantized stability.

**Numerical scope**: `test-theory` checks finite representatives, while the derivations above state the exact-arithmetic arguments. Tests do not prove theorems. SVD uses a relative 1e-10 cutoff and float64 data; numerical near-null vectors are distinguishable from exact zero in finite arithmetic.

**Corrected multi-base collision distribution (2026-11-14):** The two-point proof above fixes b. If b is instead random with an unrestricted component along u, full-image class supports can overlap and raw Bayes risk need not be zero.
