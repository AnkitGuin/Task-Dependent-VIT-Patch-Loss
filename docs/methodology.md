# Methods and measurements

**Operator**: For a C×H×W image, ordered, non-overlapping p×p patches form N=HW/p² vectors of m=Cp² entries. Qp is a permutation. Shared W∈R^{d×m} produces A=(I_N⊗W)Qp. Numerical rank uses SVD relative 1e-10, with a reconstruction/tolerance check for S1; row projection uses V_r V_r^T.

**Risk**: The Gaussian location experiment uses Y∈{-1,+1}, X|Y=y ~ N(yv/2, σ²I). Bayes token error is Phi(-||Proj_row(A)v||/(2σ)). Independent MC draws use IID equal-prior labels; the independently implemented oracle whitens Z=WX in token coordinates rather than reusing the analytic row projector or raw-space score. Pointwise 95% uncertainty uses exact Clopper–Pearson intervals. An exactly zero token contrast gives a constant prediction. A fitted logistic regression is recorded separately; it is not the oracle.

**Datasets**: S1 pairs share a base only within an example group and are split together; S2 uses completely independent, unclipped samples. S3 generates random-phase oriented gratings, class-coded markers and a nuisance-frequency variant with independent noise. S4 enumerates four equally likely binary marker combinations and defines XOR. S5 compares checkerboard signal versus independent checkerboard nuisance against low-frequency class coding. All generators use SHA-derived split seed and return versioned metadata.

**Probe and model**: Standardized logistic probes and small MLPs fit training data only. Independent split RNGs are used; noiseless XOR deliberately repeats its four support points and is not an unseen-template test. Tiny ViT uses a default two-block Transformer and mean pooling. Small CNN uses two convolutions plus adaptive pooling; neither is a Bayes oracle. Logged Transformer forward FLOPs proxy is `2Nmd + depth*(16Nd²+4N²d) + 2dK`, counting two FLOPs per multiply-add. It excludes elementwise operations, backward and optimizer work; CNN FLOPs remain unmeasured. Total/trainable parameters and optimizer steps are saved.

**Aggregation**: per-run metadata includes config SHA256, seed, environment, Git commit when available, completion status and source checksum. Experiment CSV and manifest are regenerated from completed runs. Failed cases are excluded from means and explicitly recorded. Figures F1/F2 are labeled analytic; all performance panels derive solely from actual rows. Duplicate seed-0 runs generated during verification remain in the data but should not be interpreted as independent repetitions.

**2026-11-14 corrections**: S1 bases are now perpendicular to the planted null direction; its raw sign is a true zero-risk rule in exact arithmetic. E05 phase offsets are matched between train/test and leave uniformly random phase unchanged in distribution. E07 clipping/noise prevents interpreting checkerboard annihilation alone as a zero-information theorem. New reports validate checksums and reject mixed configuration/source cohorts.
