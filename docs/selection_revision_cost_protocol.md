# Resource-measurement clarification

The final resource benchmark is run after all revision training, independent checkpoint replay and bootstrap generation, with no other project experiment executing. Earlier overlapping warm-ups are retained under `reports/selection_revision/cost_warmup_excluded` and are never analyzed as final measurements.

For each of the three domains, both budgets, eleven selectors and three repeats, a fresh child process loads the same operator/diagnostic inputs (copy-on-write memory mapping) and the frozen candidate specifications. Timing starts after imports, input mapping and pretest metadata loading. The cold stage **actually refits** the candidate operator bank on the declared operator subset, including PCA and DeiT preparation, then computes the selected metric with all required feature extraction/statistics. The fixed policy constructs only its DCT matrix. Warm-stage time starts just after operator construction. Cold time includes operator construction once, not a sum of unrelated or concurrently measured run timings. Both are recorded from the same process invocation.

RSS sampling starts before operator construction and ends after scoring, so reported peak memory includes both cold stages. Incremental peak is relative to the process baseline before fitting. Sampling interval is 10 ms and may miss transient peaks. Matrix/score replay against the final pretest bank ensures that the benchmark computes the same selection rule. Three repeats per domain/budget produce 18 measurements per selector, summarized by a median in the paper; every raw record remains available. Peak RSS includes scientific-library runtime and touched input pages. Page cache and system background activity are not controlled. The machine, two-thread numerical-library cap and common inputs are held constant.

This clarifies/strengthens the original resource paragraph by measuring cold fitting directly, rather than adding historical bank timings to a warm measurement. It changes no selector, training split, penalty, pretest choice or accuracy endpoint. The fixed-candidate lookup is genuinely free of a full-bank search; its head-training cost is still required and is outside the selection endpoint, as for all other methods. The final results explicitly distinguish selection cost from complete application training time.
