# Predeclared experiment protocol

**Historical protocol with a post-hoc correction notice:** the text below records the original 2026-11-07 design. The 2026-11-14 scientific review corrected the S1 base distribution, independent Gaussian oracle, IID MC label sampling and confidence intervals; it also fixed optional MNIST split leakage and wrapped XOR translations. These are documented repairs, not retrospectively preregistered choices. Current generator version is `patchloss-generators-v2`, and current MC coverage uses exact pointwise Clopper–Pearson intervals without the original inflated tolerance. See [review](scientific_review_20261114.md).

Written **before** primary model runs. Default synthetic dimensions: 16×16 grayscale; Gaussian S2: single 8×8 patch. Exact collisions: 32×32, 8×8 patches with a fixed 16×64 random orthonormal-row embedding. Train/test and validation are generated using independent SHA256-derived split seeds. Exact collision pairs are created and split by base template, never by patch image. Balanced class generation is deterministic per seed; XOR replicates each of four bit combinations equally.

E02 varies σ={0.25,0.5,1.0}, α={0,.25,.5,.75,1} and rank={8,16} with 6000 independent oracle Monte Carlo draws per cell; oracle agreement is assessed against ±1.96 binomial SE with a small discrete continuity allowance. E03 uses α={0,.25,.5,.75,1} with fixed rank. E04 compares balanced two-way grating discrimination against mean-matched XOR (zero noise for the latter), linear/MLP probes and mean TAR. E05 tests p={4,8}, frequency={2,4,6}, shift={0,2}, plus marker sizes={1,2,4}. E07 applies a 5×5 binomial kernel and matched raw baseline. E08 checks exact operator rank at 8×8 p=4 d=8, strides 4 versus 2, without claiming matched feature budget.

Learned model defaults: AdamW, lr=0.001 (E06 = 0.002), weight decay 0.01, batch 32, 6 epochs (E06 = 12), early stopping on validation cross-entropy, patience 3, frozen and learned projections with identical initial seeds. Tiny ViT uses two blocks, 2 heads, GELU, zero dropout, learned positional vectors and mean pooling. E09 compares frozen/learned ViTs and a CNN on S3 and S4. Main reduced CPU execution begins with seed 0; extended learned results use three seeds {0,1,2}. No test tuning. All trials including negative results remain in the manifest; a failed trial is never recorded as zero accuracy.

Success criteria: exact patch round-trip; relative collision residual <1e-8; Gaussian analytic versus MC agreement within declared sampling uncertainty in most cells (about 5% outside nominal coverage expected); valid XOR population mean symmetry; measurable model outcomes without interpreting weak probes as an information-theoretic limit. All trained comparisons report unequal parameter counts and only *proxy* FLOPs, not calibrated hardware FLOPs. Model selection is validation-only. No predeclared hypothesis is dropped on an unfavorable result. No post-hoc statistical significance testing planned; report uncertainties and effects.

Optional natural-image E10 is disabled by default because it needs network download; p=2 dense attention is not trained in CPU core due to token cost. Data generator version: patchloss-generators-v1. Runtime platform is recorded in individual `runs/*/metadata.json`. CI is CPU/offline. Scripts never download in smoke or core.
